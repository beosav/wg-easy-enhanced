# Пробный период Novir VPN

Расширенная сборка wg-easy содержит публичный API для автоматической выдачи одного WireGuard-профиля на установку приложения.

## Маршруты

- `POST /api/public/trial/start` — создать или повторно получить активный trial;
- `GET /api/public/trial/status` — получить состояние и срок доступа.

API выключен по умолчанию и не влияет на существующих клиентов.

## Переменные окружения

```yaml
environment:
  - TRIAL_ENABLED=true
  - TRIAL_SECRET=<случайная строка не короче 32 символов>
  - TRIAL_DURATION_HOURS=24
  - TRIAL_MAX_PER_IP=3
  - TRIAL_TRUST_PROXY=true
```

`TRIAL_TRUST_PROXY=true` следует включать только тогда, когда контейнер доступен через доверенный reverse proxy, который перезаписывает `X-Forwarded-For`. При прямом доступе оставьте `false`.

Секрет удобно создать на сервере:

```bash
openssl rand -base64 48
```

Не храните его в Git, документации, образе Docker или Android-приложении.

## Защита

- приложение создаёт случайный 256-битный секрет установки;
- сервер сохраняет только HMAC-SHA-256;
- повторный запрос идемпотентен;
- число новых trial с одного IP ограничивается за последние 30 дней;
- просроченный WireGuard-клиент отключается штатным cron wg-easy не позднее чем через минуту;
- приватная конфигурация возвращается только предъявителю секрета установки.

Ограничение по IP не является полной защитой от злоупотреблений. Перед массовой рекламой рекомендуется добавить Play Integrity и серверную проверку его токена.

## Запуск без остановки WireGuard

После публикации нового образа контейнер потребуется один раз пересоздать для применения миграции и переменных окружения:

```bash
docker compose pull wg-easy
docker compose up -d --no-deps wg-easy
docker compose ps
```

Создание и окончание пробных клиентов после этого применяются через `wg syncconf` и не требуют перезапуска контейнера или интерфейса WireGuard.

Перед обновлением обязательно создайте резервную копию каталога `/etc/wireguard`.

## Что требуется для публичного запуска

1. Домен или поддомен для HTTPS API.
2. Reverse proxy с действующим TLS-сертификатом.
3. Выбранный платёжный провайдер и URL страницы оплаты.
4. Политика конфиденциальности и пользовательское соглашение.
5. Для Google Play — release-ключ, карточка приложения и декларация `VpnService`.
